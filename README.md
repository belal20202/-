# لعبة الشخصية العربية 🎮

لعبة منصات 2D متقدمة مشابهة لسونك مع شخصية عربية جميلة وكارتونية.

## المميزات الرئيسية ✨

- **100 مرحلة** متدرجة الصعوبة
- **نظام متجر متقدم** لشراء الملابس والأزياء
- **شخصية عربية أصلية** جميلة وكارتونية
- **أنظمة تحكم متكاملة** (لوحة المفاتيح وأسهم الاتجاهات)
- **موسيقى وتأثيرات صوتية** احترافية
- **نظام الحفظ والتحميل** عبر localStorage
- **واجهة مستخدم رائعة** باللغة العربية

## المتطلبات 📋

- متصفح ويب حديث (Chrome, Firefox, Safari, Edge)
- اتصال إنترنت (لتحميل Phaser)

## التثبيت والتشغيل 🚀

### طريقة 1: التشغيل المباشر
1. انسخ جميع الملفات
2. افتح ملف `index.html` في المتصفح

### طريقة 2: باستخدام خادم محلي
